# 🚀 Asteroids (Python)

A Python-based recreation of the classic arcade game **Asteroids**, built using object-oriented programming principles. This project simulates player-controlled space navigation, asteroid collision mechanics, and shot-based interactions using modular Python architecture.

---

## 🎮 Features

- Real-time player movement and asteroid evasion
- Dynamic asteroid field generation and motion physics
- Object-oriented structure (Player, Asteroid, Shot)
- Collision detection for asteroids and player shots
- Scoring and gameplay mechanics
- Clean game loop structure in `main.py`

---

## 🛠 Tech Stack

- Python 3
- Pygame or Tkinter (assumed based on standard arcade implementation)
- OOP (Object-Oriented Programming)
- Custom modules (`player.py`, `shot.py`, `asteroid.py`, etc.)

---

## 📁 File Overview

| File               | Description                          |
|--------------------|--------------------------------------|
| `main.py`          | Game loop and initialization         |
| `player.py`        | Handles user control & ship logic    |
| `asteroid.py`      | Manages asteroid generation/behavior |
| `shot.py`          | Bullet mechanics and collision logic |
| `constants.py`     | Shared config variables              |
| `circleShape.py`   | Graphics helper (circle rendering)   |
| `requirements.txt` | Project dependencies (if applicable) |
